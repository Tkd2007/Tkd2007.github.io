Document AI

Financial report understanding

In progress

An end-to-end document AI system for Vietnamese financial statements. It pulls structured line items such as total assets, net revenue and profit after tax out of a report, not just its raw text.

  • Python
  • DocLayout-YOLO
  • Tesseract OCR
  • Vision-language models
  • OpenRouter

Result: on a real 54-page quarterly report, VLM extraction got all 3 target fields right. The regex baseline got 1.

Pipeline

A vision-language model reads the table and returns the target line items as structured fields.

Multimodal retrieval

Multimedia event retrieval

Final round

Search over 177,321 keyframes from 873 news videos. Describe a scene, ask a question about it, or list events in order, and it returns the matching frames.

  • Python
  • Qwen3-VL embeddings
  • Qdrant
  • PP-OCR
  • faster-whisper

Outcome: final round of HCMC AI Challenge 2026, and a team paper accepted at MMM 2027.

Pipeline

For a list of events, dynamic programming picks one frame per event and keeps them in time order.

Case study details
My part

ML evaluation

Leakage-safe fraud detection

Under review

A temporal evaluation of GP-LightGBM and SSM-XGBoost for credit card fraud detection, set up so no information from the future leaks into training.

  • Python
  • LightGBM
  • XGBoost

Status: journal article, with me as second author, under review.

Method

They're scored on later transactions, the way a deployed model would meet them, so nothing leaks backwards in time.

About

First-year Computer Science student heading toward AI engineering, with a research side.

Most of what I build turns messy input, like scanned financial statements, hours of news video or transaction logs, into structured data a program can query. I care about evaluating these systems honestly: testing on real documents rather than clean benchmarks, and checking that results hold up when the data shifts.
